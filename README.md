# MyAsthmaJournal

> A Flutter-based Android application for digital asthma diary
> management, symptom monitoring, medication tracking and
> healthcare support.

## 📱 Overview

MyAsthmaJournal is a mobile application developed as my final-year
Software Engineering project.

The application aims to replace traditional paper-based asthma
diaries with a digital platform where users can record symptoms,
track medication usage, monitor their condition and review their
health-related information over time.

## 🎯 Problem

Traditional paper-based asthma diaries can make it difficult for
patients to maintain, review and analyze their records.

MyAsthmaJournal provides a centralized digital solution for recording
and monitoring asthma-related information.

## ✨ Key Features

- 🔐 User registration and authentication
- 📝 Asthma symptom recording
- 💊 Medication tracking
- 📊 Health data visualization
- ⚠️ Symptom threshold warnings
- 🏥 Nearby healthcare facility suggestions
- 📋 Asthma assessment
- 👨‍👩‍👧 Dependent management
- 📰 Asthma-related information and news
- 📅 Appointment reminders
- 👤 User profile management
- 🔔 Local notifications
